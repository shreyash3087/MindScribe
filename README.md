## 📝 Overview

A beautiful, responsive mini-blog website built using **Next.js** and **TailwindCSS**, inspired by the provided [Figma design](https://www.figma.com/design/tIfqg7le60kPQk4Zc03NQC/Blog-Template-Light?node-id=0-419&t=h5r9GanCMh7Rn0DB-1). The project was developed for ExpertHire's frontend challenge for Mother's Day within a timeframe of 2 days.

## ✨ Features

- 📖 **Dynamic Blog Articles** - Dynamic pages for each story
- 🔍 **Advanced Search** - Find stories by keyword
- 🏷️ **Category Filters** - Browse stories by themes like "Travels", "Food", etc.
- 🗂️ **Categories Page** - Dedicated section to explore themed content
- 📸 **Instagram Highlights** - Carousels for Instagram Highlights
- 📬 **Pagination** - Pagination for articles on Homepage
- 📱 **Fully Responsive** - Perfect viewing on any device
- 💫 **Smooth Animations** - Subtle transitions and effects
- 📞 **About & Contact Pages** - Connect with the project developer
- ⚠️ **Custom 404 Page** - Stylish error handling

## 🚀 Getting Started

### Prerequisites
- Node.js 16.x or higher
- npm or yarn package manager


## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/shreyash3087/MindScribe.git
cd MindScribe
```
### 2. Install dependencies
```bash
npm install
# or
yarn install
```

### 3. Run the development server
```bash
npm run dev
# or
yarn dev
```

### 4. Visit http://localhost:3000 to see the site in action

## 🧰 Tech Stack

- **Framework:** Next.js 13+ (App Router)
- **Language:** JavaScript (React)
- **Styling:** Tailwind CSS and custom CSS
- **State Management:** Local state for interactivity
- **Hosting:** Optimized for Vercel deployment
- **Data Source:** Local JSON files
